# BankPulse - Banking System

## About the Project
BankPulse is a beginner-friendly Java console-based banking application developed as part of the Java Virtual Internship.

## Features
- Open new bank accounts
- Deposit money
- Withdraw money
- View all bank accounts
- Validate deposit and withdrawal amounts
- Automatically generate account numbers

## Technologies Used
- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## How to Run

1. Install JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the files:

   javac *.java

5. Run the application:

   java Main
